
## 教材目录的组织
这个目录是个不限层级的教材组织目录，每一个节一个目录，目录下只有一个index.md。 

## 节号

节号包括从顶层到当前层的所有节，中间以 “."隔开。例如：
01.2.3.4

其中顶层节号的位数为本教材的顶层最高节号的位数。

## 目录名字

格式：节号_中文节名_英文节名



## 前后节链接介绍
所有的 index.md， 里面的最后都有“前一节” “后一节”， “上一层”的链接。
前一节 指向本层级目录里面本节的前一个节，如果本节是第一节，则指向上层目录的前一个目录下的index.md,  
后一节 指向本层级目录里面本节的后一个节，如果本节是最后节，则指向上层目录的下一个目录下的index.md
