# 2.1.04.5 展开模式（Pattern）速查表

**介绍**: > **简介**：省略号 `...` 会将其左侧的整个模式按元素逐一复制展开：

---

省略号 `...` 会将其**左侧的整个模式**按元素逐一复制展开：

| 写法 | 展开结果示例（假设包内为 `a, b, c`） | 说明 |
| :--- | :--- | :--- |
| `args...` | `a, b, c` | 直接展开参数 |
| `&args...` | `&a, &b, &c` | 取每个参数的地址 |
| `func(args)...` | `func(a), func(b), func(c)` | 对每个参数调用 `func` 后再作为列表 |
| `func(args...)` | `func(a, b, c)` | 将所有参数一次性传给 `func` |
| `std::forward<Args>(args)...` | `std::forward<A>(a), std::forward<B>(b), ...` | 同时展开两个长度相同的包 |
