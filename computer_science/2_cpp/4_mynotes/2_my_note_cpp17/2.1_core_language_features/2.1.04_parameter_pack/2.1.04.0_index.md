# 2.1.04 C++ 参数包（Parameter Pack）详解

**介绍**: **参数包（Parameter Pack）** 是 C++11 引入的核心特性，主要用于**可变参数模板（Variadic Templates）**，允许模板接受**零个或多个**任意类型的模板参数或函数参数。它是实现 `std::tuple`、`std::make_shared`、`std::printf` 安全替代品等现代 C++ 设施的基础。

核心语法符号是省略号 `...`：
* **声明时**：`...` 在参数名**左侧**（打包）。
* **展开时**：`...` 在表达式**右侧**（解包）。
