# 1.1.1.11.5 存量 C++11/17 代码快速落地

**介绍**: 存量 C++11/17 代码快速落地

> **简介**：本节介绍“存量 C++11/17 代码快速落地”的核心概念与实践要点。

---

* **C++17 推荐做法：** `std::atomic_load_explicit` / `std::atomic_store_explicit`（针对 `std::shared_ptr`）。
* **核心思路：**
  * 利用 `<memory>` 中针对 `std::shared_ptr` 的原子自由函数，通过 `std::memory_order_acquire` 读取快照副本、`std::memory_order_release` 发布新快照。
* **特点与权衡：**
  * **优点：** 无需在业务类中显式维护 `std::mutex`，适合在已有 C++11/17 代码基础上快速接入。
  * **注意：** 该组自由函数在 C++20 中已被标记为废弃（deprecated），后续升级标准时可能需要重构；此外不同标准库实现的底层同步机制存在差异，极端高并发下需实测其争用表现。

```cpp
#include <chrono>
#include <iostream>
#include <memory>
#include <mutex>
#include <string>
#include <thread>
#include <unordered_map>
#include <unordered_set>
#include <vector>

struct PermissionSnapshot {
    uint64_t version = 0;
    std::unordered_map<std::string, std::unordered_set<std::string>> user_perms;

    bool has_permission(const std::string& user, const std::string& perm) const {
        auto it = user_perms.find(user);
        if (it == user_perms.end()) {
            return false;
        }
        return it->second.count(perm) > 0;
    }
};

struct PermissionEvent {
    uint64_t event_id;
    std::string user;
    std::string perm;
    bool grant;
};

class PermissionStore {
public:
    PermissionStore()
        : current_snapshot_(std::make_shared<const PermissionSnapshot>()) {}

    // 在线请求线程：仅在极短临界区内拷贝 shared_ptr，随后解锁做只读查询
    std::shared_ptr<const PermissionSnapshot> acquire_snapshot() const {
        std::lock_guard<std::mutex> lock(mtx_);
        return current_snapshot_;
    }

    // 异步同步线程 / Consumer：锁外构建新快照，仅在替换指针时短暂加锁
    void apply_events(const std::vector<PermissionEvent>& events) {
        if (events.empty()) {
            return;
        }

        std::shared_ptr<const PermissionSnapshot> base_snap = acquire_snapshot();
        auto next_snap = std::make_shared<PermissionSnapshot>(*base_snap);

        for (const auto& ev : events) {
            if (ev.event_id <= next_snap->version) {
                continue;
            }
            auto& perms = next_snap->user_perms[ev.user];
            if (ev.grant) {
                perms.insert(ev.perm);
            } else {
                perms.erase(ev.perm);
                if (perms.empty()) {
                    next_snap->user_perms.erase(ev.user);
                }
            }
            next_snap->version = ev.event_id;
        }

        std::shared_ptr<const PermissionSnapshot> published = std::move(next_snap);
        {
            std::lock_guard<std::mutex> lock(mtx_);
            current_snapshot_ = std::move(published);
        }
    }

private:
    mutable std::mutex mtx_;
    std::shared_ptr<const PermissionSnapshot> current_snapshot_;
};

int main() {
    PermissionStore store;

    store.apply_events({
        {1, "alice", "order.read", true},
        {2, "alice", "order.refund", true},
    });

    auto snap = store.acquire_snapshot();
    std::cout << "v" << snap->version
              << " alice order.refund = "
              << (snap->has_permission("alice", "order.refund") ? "true" : "false")
              << "\n";

    store.apply_events({
        {3, "alice", "order.refund", false},
    });

    snap = store.acquire_snapshot();
    std::cout << "v" << snap->version
              << " alice order.refund = "
              << (snap->has_permission("alice", "order.refund") ? "true" : "false")
              << "\n";
    return 0;
}
```
