在 C++17 里，标准库还没有提供 std::atomic<std::shared_ptr<T>>（那是 C++20 才加进来的），而且 C++11/17 中那组老式的 std::atomic_load / std::atomic_store 自由函数在 C++20 已经被标记为废弃（deprecated），同时在部分编译器/实现下存在性能或内存序细节问题。
