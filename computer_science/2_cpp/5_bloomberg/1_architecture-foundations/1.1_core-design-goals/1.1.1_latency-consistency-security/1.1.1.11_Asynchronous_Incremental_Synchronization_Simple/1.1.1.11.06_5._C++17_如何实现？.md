# 1.1.1.11.06 **5. C++17 如何实现？**

**介绍**: **5. C++17 如何实现？**

> **简介**：先看一个简化版本。

---

先看一个简化版本。

```
#include <memory>
#include <atomic>
#include <unordered_map>
#include <vector>

using UserId = uint64_t;
using PermissionId = uint32_t;

struct Snapshot {
    uint64_t version;

    std::unordered_map<
        UserId,
        std::vector<PermissionId>
    > permissions;

    bool has_permission(
        UserId user,
        PermissionId permission
    ) const {
        auto it = permissions.find(user);

        if (it == permissions.end())
            return false;

        const auto& list = it->second;

        return std::find(
            list.begin(), list.end(), permission
        ) != list.end();
    }
};

// 当前快照
std::shared_ptr<const Snapshot> current_snapshot;
```

## **Reader：查询线程**

```
bool check_permission(
    UserId user,
    PermissionId permission
) {
    auto snapshot =
        std::atomic_load(&current_snapshot);

    return snapshot->has_permission(
        user, permission
    );
}
```

查询线程做三件事：

1. 原子获取当前 Snapshot。
2. 在内存中查找权限。
3. 返回结果。

它不需要获取业务互斥锁，也不访问数据库。

## **Writer：后台同步线程**

```
void apply_event(const PermissionEvent& event)
{
    auto old_snapshot =
        std::atomic_load(&current_snapshot);

    auto new_snapshot =
        std::make_shared<Snapshot>(*old_snapshot);

    // 修改新快照
    new_snapshot->version = event.version;

    // 根据 event.operation 更新权限
    apply_permission_change(
        *new_snapshot, event
    );

    // 原子发布
    std::atomic_store(
        &current_snapshot,
        std::shared_ptr<const Snapshot>(
            new_snapshot
        )
    );
}
```

这里有一个重要的 C++ 知识点：

`std::atomic_load()` 和 `std::atomic_store()` 对 `shared_ptr` 的支持从 C++11 就有了。

它们是针对 `shared_ptr` 的原子操作自由函数（Atomic Shared Pointer Operations），不是普通的 `shared_ptr` 成员函数。

C++20 才正式提供：

```
std::atomic<std::shared_ptr<T>>
```

另外，这里的代码是教学示意，省略了初始化、事件排序和异常处理。
