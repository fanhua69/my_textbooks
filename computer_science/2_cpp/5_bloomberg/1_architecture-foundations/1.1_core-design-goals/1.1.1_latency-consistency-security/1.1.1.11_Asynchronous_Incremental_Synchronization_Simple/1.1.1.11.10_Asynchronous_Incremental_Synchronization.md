# 1.1.1.11.10 **Asynchronous Incremental Synchronization**

**介绍**: **Asynchronous Incremental Synchronization**

> **简介**：Database / Persistent Storage

---

**Database / Persistent Storage**

权威数据源

CDC / Event Queue

**Background Worker**

Event Processing + Incremental Update

Build + Atomic Publish

**Immutable Snapshot**

Versioned In-Memory Data

**Concurrent Readers**

Lock-free-style Read Path · Zero I/O

建议把以下技术作为后续学习路线：

| 技术                      | 主要解决的问题       |
| ----------------------- | ------------- |
| CDC                     | 如何捕获数据库变化     |
| Message Queue           | 如何可靠传递变化事件    |
| Event Sourcing          | 如何记录和重放变化     |
| Copy-on-Write           | 如何避免修改正在读取的数据 |
| Atomic Shared Pointer   | 如何原子发布新快照     |
| RCU                     | 如何高效实现读多写少    |
| Epoch-Based Reclamation | 如何安全回收旧对象     |
| Versioning              | 如何检测数据陈旧和事件乱序 |

**我特别建议你下一步深入研究 RCU（Read-Copy-Update）。**

它和这里的 Immutable Snapshot 思想非常接近，而且是 Linux 内核以及高性能并发系统中非常重要的一种技术。对于你研究 Bloomberg Entitlement 的 Low-Latency Architecture，尤其值得掌握。
