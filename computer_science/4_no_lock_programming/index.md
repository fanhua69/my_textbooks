# 4 No-Lock Programming：C++ 无锁编程

**介绍**: 一套面向现代 C++ 并发与高性能系统开发的无锁编程系统教材。从并发拓扑（SPSC、SPMC、MPSC、MPMC）和进度保证出发，深入 CPU 原子操作、C++ 内存模型、CAS、线性化、ABA、经典无锁数据结构与安全内存回收，并覆盖性能工程、正确性验证及低延迟系统实战。以 C++11 为基础，覆盖 C++14/17/20/23 并跟踪 C++26；同时比较 x86-64 与 ARM64 平台行为。
