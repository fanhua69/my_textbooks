# 3.3.1.1 三个尺度：架构模式、设计模式与惯用法 (Idioms)

**介绍**: 架构模式（如分层、MVC、微服务）作用于整个系统或子系统；设计模式（如 GoF 23 种）作用于若干类的协作；惯用法（如 RAII、PImpl）作用于单一语言的具体写法，三者逐级细化并相互支撑。
