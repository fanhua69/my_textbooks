# 11.3.1.5 特性开关 (Feature Flags) 与暗启动 (Dark Launch)

**介绍**: 将代码部署与特性发布彻底解耦，在后台隐蔽运行生产真实流量（Dark Launching），支持面向特定租户动态开关功能。特性开关又称 Feature Toggle，需配合开关生命周期治理，避免陈旧开关累积成技术债。
