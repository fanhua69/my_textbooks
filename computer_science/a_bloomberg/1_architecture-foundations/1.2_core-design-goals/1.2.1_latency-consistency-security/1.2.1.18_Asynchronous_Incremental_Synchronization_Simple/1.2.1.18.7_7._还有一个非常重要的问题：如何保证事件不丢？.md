# 1.2.1.18.7 **7. 还有一个非常重要的问题：如何保证事件不丢？**

**介绍**: **7. 还有一个非常重要的问题：如何保证事件不丢？**

> **简介**：假设数据库已经提交了 Version 101，但后台同步线程突然崩溃。

---

假设数据库已经提交了 Version 101，但后台同步线程突然崩溃。

此时：

```
Database Version: 101
Memory Snapshot:  100
```

如果系统没有恢复机制，内存权限就会一直落后。

因此，通常会维护：

```
struct SyncStatus {
    uint64_t database_version;
    uint64_t snapshot_version;
};
```

监控：

```
Replication Lag =
    database_version - snapshot_version
```

恢复机制通常包括：

1. 持久化事件日志。
2. 记录最后处理的事件序列号。
3. 后台线程重启后从 Checkpoint 恢复。
4. 如果无法确定数据完整性，重新加载完整快照。
