# 1.2.1.07.2 举个例子：银行账户转账

**介绍**: 举个例子：银行账户转账

> **简介**：假设有两个服务器：

---

假设有两个服务器：

**Server A**

# **&#x20;$1,000&#x20;**

**Server B**

# **&#x20;$1,000&#x20;**

Network Partition

两个服务器之间网络断开

A 和 B 无法相互同步数据。

现在，用户在 Server A 上取走 $200。

Server A 的余额变成 $800。

但是 Server B 仍然是 $1,000。

这时有两种选择：

## 方案一：选择 CP（Consistency + Partition Tolerance）

优先保证一致性。

- Server B 无法确认最新余额。
- 暂停部分读取或写入请求。
- 等待网络恢复、数据同步。

结果：数据一致，但部分请求无法正常完成。

## 方案二：选择 AP（Availability + Partition Tolerance）

优先保证可用性。

- Server A 继续处理请求。
- Server B 也继续处理请求。
- 两边可能暂时返回不同的余额。

结果：服务保持可用，但数据可能暂时不一致。
