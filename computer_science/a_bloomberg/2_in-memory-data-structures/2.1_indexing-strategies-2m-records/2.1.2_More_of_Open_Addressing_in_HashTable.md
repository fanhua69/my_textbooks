# 2.1.2 More_of_Open_Addressing_in_HashTable

**介绍**: More_of_Open_Addressing_in_HashTable

---

开放寻址（Open Addressing）是哈希表解决冲突的一种核心内存布局策略：表内元素总数不超过槽位容量（$N \le M$），**所有键值对直接存放在同一张连续数组中，不使用链表节点指针**；当算出的初始槽位已被占用时，按既定探测规则在数组内顺序或跳跃寻找下一个空槽位。

---

### 1. 为什么工程上偏爱 Open Addressing？

在现代 CPU 架构下，传统“链地址法（Separate Chaining）”常见痛点是每个节点独立堆分配 + 指针跳转，导致访存分散、缓存命中率下降；开放寻址则把优势押在**连续内存与硬件局部性**上：

* **缓存局部性好（Cache Locality）**：槽位紧挨着排列。一次加载 64 字节缓存行（Cache Line）时，往往能顺带把相邻几个槽位读入 L1/L2 缓存，线性探测时命中率很高。
* **零节点指针与更少堆分配**：省去每个桶/节点的额外指针开销和频繁小块分配，内存占用更紧凑、分配器压力更小。
* **负载因子上限刚性**：开放寻址无法像链表那样把多个元素塞进同一个槽位，因此**负载因子 $\alpha = N / M$ 必须严格小于 1**（通常控制在 0.5–0.85），一旦接近阈值就必须扩容（Rehash）。

---

### 2. 三种经典探测策略

当初始槽位 $h(k)$ 已被占用时，第 $i$ 次探测（$i = 1, 2, \dots$）访问的位置由探测函数决定：

| 探测方式 | 位置公式 | 特点与代价 |
| --- | --- | --- |
| **线性探测（Linear Probing）** | $(h(k) + i) \bmod M$ | 步长为 1，顺序向后找空位；缓存最友好，但容易形成**一次聚集（Primary Clustering）**，连成片的占用区会让后续冲突变长。 |
| **二次探测（Quadratic Probing）** | $(h(k) + c_1 i + c_2 i^2) \bmod M$ | 探测步长随 $i$ 增大而跳跃，能打散连续长块，减轻一次聚集，但可能出现**二次聚集**，且表长或系数需满足条件才能保证探测到空槽。 |
| **双重哈希（Double Hashing）** | $(h_1(k) + i \cdot h_2(k)) \bmod M$ | 用第二个独立哈希函数 $h_2(k)$ 决定步长（通常保证与 $M$ 互质），聚集最少，但跳跃跨度大，可能增加跨缓存行访存。 |

---

### 3. 删除与扩容：开放寻址的两个关键细节

* **不能直接置空（墓碑 Tombstone / 后向移动）**：如果删除元素后直接把槽位设为空，会截断后面冲突元素的探测链，导致后续查找误判“不存在”。常见做法是放一个墓碑（Tombstone）**标记（查找跳过、插入可复用，但过多会拉低效率），或者把后面符合条件的冲突元素**向前平移（Backward Shift）填补空位。
* **扩容（Rehash）不可缺**：随着元素增多，探测链会变长，平均查找步数迅速上升。通常在有效元素加上墓碑达到阈值时，分配更大的新数组（如 2 倍容量）并重新哈希插入全部有效条目。

---

### 4. 现代工业界的演进变体

纯教科书式的线性探测在高负载或长探测链下仍有短板，现代高性能哈希表常在此基础上做增强：

* **Robin Hood Hashing（罗宾汉哈希）**：记录每个元素偏离“理想槽位”的距离（PSL, Probe Sequence Length）；新元素探测距离更远时，可“劫富济贫”挤占距离更近的元素，让探测长度分布更均匀、最坏情况更可控。
* **SwissTable / SIMD 分组探测**：把控制字节（如 1 字节元数据：空、墓碑、或 7-bit 指纹）集中存放，用 SIMD 指令一次比对 16 个槽位状态，再跳去读取对应键值对，大幅减少无效键比较。

---

### 5. C++ 最小可运行示例（线性探测 + 墓碑）

```cpp
#include <cstddef>
#include <cstdint>
#include <iostream>
#include <optional>
#include <vector>

class LinearProbeMap {
public:
    explicit LinearProbeMap(size_t initial_cap = 16)
        : slots_(next_pow2(initial_cap < 8 ? 8 : initial_cap)) {}

    bool insert(uint64_t key, int value) {
        if (static_cast<double>(size_ + tombstones_ + 1) / slots_.size() > 0.7) {
            rehash(slots_.size() * 2);
        }

        const size_t mask = slots_.size() - 1;
        size_t idx = mix64(key) & mask;
        size_t first_tombstone = npos;

        while (true) {
            Slot& s = slots_[idx];
            if (s.state == State::Occupied) {
                if (s.key == key) {
                    s.value = value;
                    return false;
                }
            } else if (s.state == State::Tombstone) {
                if (first_tombstone == npos) {
                    first_tombstone = idx;
                }
            } else { // State::Empty
                size_t target = (first_tombstone != npos) ? first_tombstone : idx;
                if (slots_[target].state == State::Tombstone) {
                    --tombstones_;
                }
                slots_[target] = Slot{key, value, State::Occupied};
                ++size_;
                return true;
            }
            idx = (idx + 1) & mask;
        }
    }

    std::optional<int> get(uint64_t key) const {
        const size_t mask = slots_.size() - 1;
        size_t idx = mix64(key) & mask;

        while (true) {
            const Slot& s = slots_[idx];
            if (s.state == State::Empty) {
                return std::nullopt;
            }
            if (s.state == State::Occupied && s.key == key) {
                return s.value;
            }
            idx = (idx + 1) & mask;
        }
    }

    bool erase(uint64_t key) {
        const size_t mask = slots_.size() - 1;
        size_t idx = mix64(key) & mask;

        while (true) {
            Slot& s = slots_[idx];
            if (s.state == State::Empty) {
                return false;
            }
            if (s.state == State::Occupied && s.key == key) {
                s.state = State::Tombstone;
                --size_;
                ++tombstones_;
                return true;
            }
            idx = (idx + 1) & mask;
        }
    }

private:
    enum class State : uint8_t { Empty, Occupied, Tombstone };

    struct Slot {
        uint64_t key = 0;
        int value = 0;
        State state = State::Empty;
    };

    static constexpr size_t npos = static_cast<size_t>(-1);

    static size_t next_pow2(size_t n) {
        size_t p = 1;
        while (p < n) p <<= 1;
        return p;
    }

    static uint64_t mix64(uint64_t x) {
        x += 0x9e3779b97f4a7c15ULL;
        x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
        x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
        return x ^ (x >> 31);
    }

    void rehash(size_t new_cap) {
        std::vector<Slot> old = std::move(slots_);
        slots_.assign(new_cap, Slot{});
        size_ = 0;
        tombstones_ = 0;
        for (const auto& s : old) {
            if (s.state == State::Occupied) {
                insert(s.key, s.value);
            }
        }
    }

    size_t size_ = 0;
    size_t tombstones_ = 0;
    std::vector<Slot> slots_;
};

int main() {
    LinearProbeMap map;
    map.insert(1001, 42);
    map.insert(1017, 99);
    map.erase(1001);

    if (auto v = map.get(1017)) {
        std::cout << "1017 -> " << *v << "\n";
    }
    return 0;
}

```
