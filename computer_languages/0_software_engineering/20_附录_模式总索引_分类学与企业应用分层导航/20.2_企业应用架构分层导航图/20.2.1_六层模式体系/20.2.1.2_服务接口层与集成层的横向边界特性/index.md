# 20.2.1.2 服务接口层与集成层的横向边界特性

服务接口与集成通信并非业务逻辑与数据访问之间的上下级，而是系统对外暴露能力与系统间通信的横向边界，实际项目中可与其他层并列或交叉；并区分服务接口层与业务逻辑层中的服务层 (Service Layer)。
