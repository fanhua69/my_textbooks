你根据write_book.py把json文件修改一下:目录名字要使用多级节号，比如2.1.3_测试要点

Grok

已根据 write_book.py 的逻辑，把 JSON 里所有节点的 slug 改成了多级节号形式。

修改说明

  • 每个节点的 slug 现在格式为：{节号}_{标题}
  • 示例：
    • 1_软件工程全景与过程方法论
    • 1.1.1.2_本质复杂度与偶然复杂度
    • 2.1.3_用户画像构建与同理心地图
    • 7.2.1.1_经典测试金字塔
  • 共更新 507 个节点，旧的英文描述式 slug 已全部替换
  • 标题中的英文括号注释（如 （布鲁克斯《没有银弹》））已去掉，使目录名更简洁
  • 非法路径字符已做安全处理，中文完整保留

修改后的文件已保存到：

/home/workdir/artifacts/0_software_engineering.json

直接用现有的 write_book.py 生成目录即可，目录结构会变成：

│   ├── 1.1_软件工程概论与全景/

│   │   │   ├── 1.1.1.1_软件危机的历史根源与典型历史教训/
│   │   │   └── ...
│   └── ...

└── ...
