# 0_low_latency_software_engineering

一套面向“低延迟软件工程技术及开发”的体系化教材大纲：自延迟度量学与性能工程方法论出发，纵向贯通 CPU 微架构、操作系统内核（含 NUMA/绑核/大页实战）、网络与内核旁路（DPDK/Solarflare Onload）、C++ 语言级优化、并发与无锁编程、数据结构与算法、消息与事件驱动架构、存储与数据库、分布式尾延迟治理、托管运行时、硬件加速（FPGA/SmartNIC/GPU/NPU），横向覆盖电子交易（含市场微观结构、FIX/ITCH/OUCH 协议、Tick-to-Trade 优化实战）、实时音视频、游戏与 XR、嵌入式与机器人、移动端与 Apple 平台、Web 前端、AI 推理等典型领域，并配套剖析与可观测性、测试与发布运维、安全与延迟权衡、端到端综合案例与速查附录。
